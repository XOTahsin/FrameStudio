LEARN THE WORKFLOW

Quick guide

A practical guide to preparing reliable, repeatable photo frame mockups.

01

Prepare a scenario template

Use a sharp, well-lit photo with a visible frame. Upload it and FrameStudio will attempt to detect the frame opening automatically. Review the four numbered handles, fine-tune them if needed, then save the template.

  • Use Auto-detect for an initial corner suggestion, even when artwork is already inside the frame.
  • Mark the inner artwork area, not the outer frame edge; auto-detection is a suggestion and should be checked.
  • Keep the point order clockwise: top-left, top-right, bottom-right, bottom-left.
  • Use the same scenario image and pixel dimensions for every render.
02

Preserve glass reflection

For a convincing glass effect, add a transparent PNG reflection overlay that matches the full scene dimensions. Bright reflection pixels should be visible; the rest should be transparent.

  • Use a separate overlay exported from your layered design source when possible.
  • Choose Screen for bright glare, Soft Light for a subtle sheen.
  • Keep reflection opacity modest and consistent across products.

FrameStudio does not claim to perfectly extract reflections from every flattened image. If reflection and old artwork are merged, clean separation may require manual masking in an image editor.

03

Generate your mockups

In Mockup Studio, upload your new artwork, tick the scenarios you need and press Generate. The image is perspective-warped into each saved quadrilateral.

  • Cover crops artwork to fill the frame's aspect ratio.
  • Stretch uses the full artwork and can distort it.
  • Render at the scene's native size or choose a larger output width.
04

Back up your templates

Templates are stored in this browser's local database. Export important templates as .framekit files and keep a backup alongside your original scene and overlay assets.

  • Use Export in the template library to create a portable template file.
  • Import .framekit files on another device or browser.
  • Clearing browser data can remove locally stored templates.

About FrameStudio

FrameStudio 1.1.0 is a browser-based, offline-first mockup compositor. It uses the Canvas API and a local perspective mesh renderer. No AI API or account is required.
